# ADR-0056: 正常完走の確認まで出力契約を最新版で実行する

- Status: Accepted
- Date: 2026-10-05
- Decision owner: Repository owner
- Authority: 「既存試合の継続も最新版に統一」および更新されたゴール第5項
- Supersedes: [ADR0053](0053-awareness-response-completion-repair.md), [ADR0055](0055-consistent-awareness-narration-contract.md)

## Context

E-LC-01: 所有者は既存試合の継続を含めた最新版の出力契約を指定し、プロンプト固定の開始条件を正常完走試験の完了とした。E-LC-02: 旧方針では旧版の実況指示が継続経路に残る。保存された実況資料には内容・観測範囲・スタイルと旧出力書式が混在している。

## Decision drivers

C-LC-01: 送信する各役割の出力契約を最新の検証済みスキーマと一致させる。C-LC-02: 世界・キャラ・スタイルの不変束縛、発声原文、知識境界と履歴を維持する。C-LC-03: 正常完走の実測より先に不具合を含む指示を固定しない。

## Considered options

1. 旧試合だけ旧指示を使う: 所有者の指定に反する。
2. 旧出力指示に最新指示を追記する: 矛盾が残る。
3. 最新出力指示で実行し、履歴は保持する: 採用。

## Decision

正常完走試験の完了が証拠として記録されるまで、新規試合と既存試合の継続は最新版の出力契約で実行する。保存された旧プロンプト版は履歴であり、その旧出力指示を実行する根拠にはしない。正常完走試験の完了後に、その時点の検証済みプロンプトを固定する。完了証拠がない現時点では固定開始済みとは扱わない。

潜在・顕在の旧版分岐は最新の出力説明へ統一する。実況の直接呼出しは既存の公開応答型を保ちながら最新の厳密な役割別指示を用いる。実況batchは一つのreceipts契約を用いる。古い凍結資料は、実装で登録された旧書式の完全一致箇所と旧句読点変更許可だけを送信前に置換し、観測範囲・スタイル・資料本文を保つ。任意のJSONらしい文章を正規表現で削る方式は採用しない。保存資料自体は書き換えない。

ADR0053の物理応答完了の会計処理、ADR0055の内容と出力書式の分離・応答診断は引き続き適用する。今回変更するのは旧版実行と固定開始条件である。

## Consequences

既存試合の継続の出力指示も修正できる。旧指示での完全な再実行は保証しない。正常完走の成功は現時点で未確認であり、ローカルテストだけでは固定条件を満たさない。

## Compatibility and migration

正準ルール、エンジン版、公開DTO、モデル、待機期限、リトライ方針を変更しない。履歴と不変アセットを保持する。登録済み旧書式の変換は実況送信資料だけに適用し、実送信内容からdispatch検証を行う。既存の保留中V3切替試行は対象外。

## Verification

実装のbuilderから生成する全実況phaseの指示、旧版・版なし資料の継続、厳密なspeech一致・知識境界・スタイル保持、潜在・顕在の旧版指定でも最新説明、型検査と関連回帰を検証する。公開反映後の新規試合終了・実況公開・実利用トークン記録を正常完走の証拠として確認する。
