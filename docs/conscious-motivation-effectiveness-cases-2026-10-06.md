# 顕在意識の動機・履歴設計 有効性確認用の場面 第1版

対象: [基本設計](conscious-motivation-and-history-design-2026-10-06.md)。状態: 比較用資料、実モデル評価は未実施。以下は架空の場面であり、正準試合やキャラへ追加する事実ではない。

## 比較の目的

行動数や発言の多様さではなく、持続する目的と本人の経験から「今、何を変えようとし、そのために何を選ぶか」が成立するかを見る。正当な反復・待機・沈黙を失敗にしない。

| 場面 | 共通資料 | 効果を判断する観点 |
|---|---|---|
| 要求が無視される | 目的は仲間を守る。退くよう求めたが相手は返答せず、仲間へ近づいた。合法な移動・発声等を提示 | 目的と相手の現在行動を結び、今回の働きかけを選べる。単に同じ要求を繰り返す場合も、その意味が現在の意思にあるかを見る |
| 相手が協力する | 同じ目的・要求の後、相手は「分かった」と言って離れ、本人は離れたことを見た | 以前の敵対的な要求を機械的に続けず、距離の確保に応じた意思を持てる。攻撃の強制をしない |
| 衝動と目的が衝突する | 目的は仲間を守る。相手は前方、仲間は後方。潜在の感じは怖くて退きたい | 衝動を知らない説明へ変換せず、目的と身体的な怖さをともに受けて行動する。衝動に従う/踏みとどまるのどちらも本人に沿えば許容 |
| 過去の約束が現在に効く | 直近は静かな場面。以前に本人が仲間へ「ここで待つ」と約束している | 約束が直近窓外でも根拠を持って残り、目的ある待機が可能。新規行動を強制しない |
| 相手の発言へ答える | 相手「何を守ろうとしている？」。本人は問いを聞き、答えられる範囲の事情を知っている | 問いに対応する発声・沈黙・行動を意思と一緒に選べる。再度遭遇の説明だけをしない |
| 実行が進まない | 目的と意思は明確、自由行動を選ぶが、本人には成立が確認できない | 同じ意思の表現を増やすだけで改善扱いにしない。意図的な再試行と裁定側の停滞を分け、原因調査へ戻す必要を判断する |

## 比較条件

基本設計のA/Bを比べる際は、同じモデル・同じ現在状態・同じ人物と合法候補・同じ知覚情報を用いる。片方だけ有利な新事実を加えない。まず入力に何が足りるかを静的に確認し、実モデル比較の件数・予算・評価基準は別に確定する。

A/Bは指示・状態構造・履歴構造を同時に変えるため、それだけではどの要素が効いたかを特定できない。必要なら「短い指示＋同じ経験資料」とBの比較を追加し、ラベル差分の寄与と履歴の寄与を分ける。この資料だけで追加の有料呼び出しを許可しない。

記録対象は、場面入力、モデル・プロンプト改訂、状態差分、選択した意欲/発言、目的との接続、知覚範囲の違反、正当な継続、入力/出力/合計のSDK実トークンである。人間の読解評価と機械契約の合否は区別する。
