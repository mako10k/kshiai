# バージョン表示ルール

2026-10-05、所有者の「何のバージョンなのか分かるようにする」という指示に基づく。

- 文書、画面、作業報告では **対象名 + バージョン** を一組で表示する。単独の「V3」「V4」「V5」は使わない。
- 初出では対象の意味を短く説明する。複数の対象を一つの番号でまとめない。
- 保存済みのschemaVersion、pipeline ID、revision ID、ファイル名は表示の都合だけで変更しない。技術的な識別子を示す場合も対象名を添える。
- 履歴資料・既存契約の一括置換は行わず、新規記述と今回変更する表示へ適用する。

| 対象 | 表示例 | 意味 |
| --- | --- | --- |
| キャラクター定義 | キャラクター定義 v3 | 能力・特性・行動原理を保存する形式 |
| 試合束縛形式 | 試合束縛形式 v5 | 試合が使う不変資産・ルール・パイプラインの束縛形式 |
| 意識パイプライン | 意識パイプライン awareness-v5 | 潜在・顕在・意欲・知覚・実況を分離する処理方式 |
| 試行運用ポリシー | 試行運用ポリシー awareness-v5-usage-v1 | 時間・呼び出し上限と実利用計測の設定 |
| 設計文書 | 意識パイプライン基本設計 第2版 | 文書の改訂番号。データ形式の番号とは別 |

例：**キャラクター定義 v3を使い、試合束縛形式 v5で作成した試合を、意識パイプライン awareness-v5で進める。**
