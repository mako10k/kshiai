# 意識出力形式 v2：必須の優先記憶配列

Accepted ADR-0070 revision1。意識パイプライン unified-consciousness-v1で、意識ポリシー v3と意識プロンプト v3を明示選択する試験用契約。公開作成の既定は意識ポリシー v2のまま。

```json
{
  "action": { "kind": "defend" },
  "speech": "受け方を変える。",
  "memory": ["3", "防御だけでは打開できない。次は攻撃へ切り替える", "1"]
}
```

`memory`は毎回必須、最大5件。配列の先頭が次の優先順位1。正確な文字列`"1"`〜`"5"`は、入力にある更新前の記憶順位を参照する。上の例は旧3位、新規本文、旧1位を残し、旧2位等を削除する。すべての参照は同じ更新前配列に対して解決し、途中の並べ替えには影響されない。

新規本文は1〜400 Unicode code point。既存参照はIDと本文を保持し、新規本文にはサーバーが判断IDと配列位置に基づくIDを付ける。本文の意味は機械判定しない。数字1〜5単独は参照専用。

変更不要なら既存順位を順に並べる。`[]`は全削除であり、保持すべき考えがない場合も許可する。空欄を埋めることは要求しない。存在しない順位、同じ参照の重複、6件以上、空文字、文字数超過、memory省略/nullは返答全体の契約失敗。意識出力形式 v1の`memoryOperations`との併用も拒否する。

行動と発話を選んだ後、意図・注意・気づきを見直して、同じ意識応答内で記憶配列を出す。追加のターン終了LLM呼び出しは行わない。保存と次の入力への反映は既存の世界commitと同じtransaction/fenceで行い、片側失敗や遅延結果では記憶を先に適用しない。本文は公開DTOや実況へ渡さない。

保存済みの意識ポリシー v1/v2、意識プロンプト v1/v2、意識出力形式 v1は変更しない。データベース移行は不要。意識出力形式 v2の必須欄は、実モデルが有用な記憶を作ることや費用削減を保証しない。
