## 確認できた問題

1. **主判断34件中25件が棄却され、台詞だけが残る。** 保存入力を現在の純粋な行動検証・意識判断受理関数で再検証すると、13件は action_invalid、11件は goal_invalid、1件は intent_invalid。マコトはターン5〜12で利用可能行動にない同じ技を8回連続で再提案している。ネヴァの11件は、既存目標がある場合に明示的な null を要求する initialGoal フィールドの欠落である。実際にモデルが契約上必須のフィールドを返していない問題であり、業務値を固定文字列に置き換えて解消すべき問題ではない。
2. **棄却理由と次の判断へのフィードバックが不十分。** battle-service.ts の agencyAcceptance 不成立処理は理由を schema_invalid に上書きするため、利用不能な技・目標フィールド欠落・意図参照不備を保存トレースから区別しにくい。次の判断に渡る actionFeedback は実行された行動の結果であり、ターン6のマコトには basic_attack が成立したとの情報が渡る。直前の技提案が棄却された理由とは異なる。棄却した提案を再考するための情報を別途正確に連携する必要がある。
3. **自由行動2件とも成立していない。** ターン2・4の小道具を使える状態にする試みは、いずれも adjudication_unavailable で失敗。description と subjectRefs は存在し、先の欠落による型エラーとは別問題である。対応する警告ログは見つからず、プロバイダー障害と断定できない。prepareFreeActionsForTurn は plannedAction から判定対象を組み立てるが、呼び出しはバケット解決後にある。解決済み actions と準備対象の受け渡し不整合が疑われ、追加検証が必要。最終 semanticState.revision は0。worldState.revision は5で移動等の変化はあり、全状態が不変という意味ではない。
4. **同じ台詞と描写が反復する。** マコトの「……その灯守、ひとりでここに留まっているわけではないようだな。」は5回、「……足音の間隔、すでに二人の灯守の癖と重なっているようだな。」は4回。地の文も灯杖を払う・肩を掠める・間合いを測る描写が反復する。20件のナレーションはすべて completed で fallback_reason は null。単なる失敗時テンプレートへの切替としては説明できない。
5. **結末が確定結果を弱くしか表現しない。** 敗者のHPは0で戦闘不能、後日談入力には勝者と fallenNames があるが、出力には「マコトが静かに立ち」とあり、敗北や決着の変化が伝わりにくい。
